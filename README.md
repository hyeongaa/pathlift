# PathLift project page

Static GitHub Pages site for **PathLift: Depth-Conditioned Metric Lifting for Visual-Navigation Priors** (CoRL 2026).

## Preview locally

Run `python3 -m http.server 8000` from this folder and open <http://localhost:8000>.

## Publish with GitHub Pages

In the GitHub repository, open **Settings → Pages**. Select **Deploy from a branch**, choose `main` and `/(root)`, then save.

This folder contains only the site files: the page, figures, paper PDF, and compressed web video. The original high-bitrate video and supplementary appendix remain in the parent project folder and are not part of this site repository.
